## 3. วิเคราะห์ผลการทำงาน (Retro Matrix)

### What Went Well (สิ่งที่ทำได้ดีและควรรักษาไว้)

* การสื่อสารภายในทีมรวดเร็วและชัดเจนผ่านช่องทางแชต
* มีการช่วยกันแก้บั๊กและ Review Code สม่ำเสมอ

### What Didn't Go Well (ปัญหาหรืออุปสรรคที่พบ)

* การประเมินเวลา (Estimation) บาง Task ต่ำกว่าความเป็นจริง
* ความชัดเจนของ Requirement ช่วงต้นสปรินต์ยังไม่นิ่ง

### What We Learned (สิ่งที่ได้เรียนรู้)

* ควรแบ่ง Task ย่อยให้เล็กลงเพื่อให้ตามสถานะได้ง่ายขึ้น
* ควรอัปเดต blocker ทันทีใน Daily Scrum ไม่ควรรอให้ถึงวันสรุปงาน
